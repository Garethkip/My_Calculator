# 🧮 My Calculator

## 🌐 Live Demo
**https://garethkip.github.io/My_Calculator/**

A simple and responsive web-based calculator built with **HTML, CSS, and JavaScript**.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Decimal number support
- 🧹 Clear/reset functionality
- 📱 Responsive design
- ⚡ Runs directly in the browser

## 🛠️ Technologies Used

- **HTML5** — Structure
- **CSS3** — Styling and layout
- **JavaScript** — Calculator logic and user interaction
- **GitHub Pages** — Deployment
